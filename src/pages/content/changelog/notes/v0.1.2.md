# v0.1.2

## Features
- **Folder Rename**: Added an explicit `✎` button to easily rename folders from the sidebar.
- **Auto Bumping**: Added automated version bumping scripts to simplify our release pipeline.

- **Glassmorphism**: Added responsive glassmorphism background to the timeline track.
- **Solid Markers**: Fixed visual weight mappings to accurately render 10px solid tracking markers for complex conversations.
